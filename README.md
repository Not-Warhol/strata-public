# STRATA.

An ecosystem built on Avalanche, about Avalanche: generative art drawn from on-chain history, on-chain games, a physical print store, a marketplace and collaborations with ecosystem projects.

Site: https://straata.xyz

This repository is a public extract prepared for a grant application. It holds the contracts, the art generators and the drop definitions. The production server (quote signing, metadata, store, anti-abuse) stays private.

## How the art is made

1. **Read.** The server reads the wallet's history from the C-Chain (balances through Multicall3, transactions, protocol use).
2. **Seal.** At mint a seed is stored on-chain: `keccak256(drop, minter, data, index)`. The data read is stored with it.
3. **Draw.** One deterministic generator turns seed and data into the piece. After the seed there is no randomness.
4. **Prove.** The browser (p5) and the server (SVG) produce the same picture, so anyone can redraw a token and check it.

A wallet's own piece is not shown before its mint is final, so nobody can shop for a better result.

- `shared/art.js`: Contour. Each collection held raises a peak in its colour, bag size sets the height, total NFTs set the contour lines, texture is a halftone hillshade under a seeded light.
- `shared/persona.js`: Persona. A mask split into one lot per past transaction; every new transaction raises a building, a failed one blinks red.
- `shared/pharaoh-traits.js`: HYPOGEUM traits from the token's on-chain seed.
- `shared/strata-print-*.js`: the generators behind the physical prints.

## Contracts

`contracts/contracts/`: `StrataDrop` (open edition inside a mint window, signed per-wallet allowance, ERC-2981 royalties, `contractURI`), `PersonaDrop`, `StrataReceipt`, `StrataReseed`, and the Market set (`StrataAuction`, `StrataZone`, `StrataNames`, `StrataTransfer`) with staking and rewards.
